# 组件开发指南（v1）

> 面向**外部开发者**：照着这份文档，你可以不碰主程序任何代码，做出一个能装进
> 桌面、能拖动、能配置、能进组件库的桌面小组件。
>
> 最短路径：复制 `examples/widgets/hello/` → 改 `manifest.json` 的 id 与名字 →
> 改 `widget.py` 的绘制 → `python tools/widget_dev.py 你的目录` 看效果 →
> `python tools/pack_widget.py 你的目录` 出 zip → 主程序 ▸ 设置 ▸ 组件库 ▸
> 「导入组件…」。全程不需要重启主程序（导入后组件库立刻出现新卡片）。
>
> 配套：规格背景见 [指导文档_v9](指导文档_v9.md) §4；内部实现与踩坑见
> [DEVLOG](../DEVLOG.md) §8。

## 1. 一个组件由什么组成

```
my_widget/                 ← 目录名随意，真正的身份是 manifest 里的 id
  manifest.json            ← 必填：组件的一切"静态事实"
  widget.py                ← 必填：一个 GlassWidget 子类（文件名可用 module 改）
  preview.png              ← 可选：本文件不参与运行，只是你留的素材
  README.md                ← 可选：说明、作者、许可
```

打 zip 时**只收**这些后缀：`.py .json .md .txt .png .jpg .jpeg .gif .svg .ico .webp`。
其它后缀（`.exe`、`.bat`、`.dll`…）会让整包导入失败——这是刻意的。

## 2. manifest.json 字段表

```json
{
  "id": "hello",
  "name": "示例组件",
  "summary": "向世界问好，可显示时间",
  "category": "示例",
  "spans": [[2, 2], [4, 2], [2, 4]],
  "module": "widget.py",
  "factory": "HelloWidget",
  "anchored": true,
  "interactive": false,
  "multi": false,
  "version": "1.0.0",
  "settings": [
    {"key": "who", "label": "称呼", "kind": "text", "default": "世界"},
    {"key": "show_time", "label": "显示时间", "kind": "bool", "default": true}
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 组件唯一身份。小写字母开头，只用 `a-z 0-9 _`，2~31 位。**不能与内置组件同名**（`clock` `notes` `panel` `monitor` `todo` `calendar` `weather` 都被占用了） |
| `name` | 是 | 组件库里显示的名字 |
| `summary` | 否 | 一句话说明，显示在卡片名字下面 |
| `category` | 否 | 组件库分组，默认「其他」。写已有分类（时间 / 效率 / 系统 / 信息）就会并进去 |
| `spans` | 否 | 允许的尺寸，`[列, 行]` 数组，**第一项是默认**。每项 1~12 格，省略 = `[[2,2]]` |
| `module` | 否 | 组件类所在文件，默认 `widget.py`，必须是同目录下的 `.py` |
| `factory` | 是 | 组件类名（`GlassWidget` 的子类） |
| `anchored` | 否 | 默认形态：`true` = 锚定（长在桌面上，占格子），`false` = 悬浮卡片。默认 `true` |
| `interactive` | 否 | 组件是否接受键盘焦点（有输入框才需要 `true`）。默认 `false` |
| `multi` | 否 | 是否允许多个实例。默认 `false`（组件库里已添加后按钮变「已在桌面」） |
| `version` | 否 | 你自己的版本号，只用于展示与排查 |
| `settings` | 否 | 设置项声明（见 §5）。不写 = 右键菜单里没有「组件设置…」 |

> 外观（背景色 / 透明度 / 文字色 / 强调色 / 圆角）**不用声明**，所有组件都
> 自动拥有，代码里读 `self.style` 就拿到了。

## 3. 组件类：只写"画什么"

```python
from PySide6.QtCore import QRectF, Qt
from PySide6.QtGui import QColor

from deskorg import theme
from deskorg.widget_glass import GlassWidget


class MyWidget(GlassWidget):
    def paint_content(self, p):
        """画自己的内容。坐标一律按 self.rect() 的比例算，别写死像素。"""
        r = QRectF(self.rect())
        p.setPen(QColor(self.style.text))
        p.setFont(theme.ui_font(max(12, int(r.height() * 0.14)), bold=True))
        p.drawText(r, Qt.AlignCenter, "你好")

    def on_settings_changed(self):
        # 必须调 super()：它负责清样式缓存并重绘
        super().on_settings_changed()
```

### 3.1 你从基类白拿的能力

| 能力 | 说明 |
| --- | --- |
| 玻璃底 | 竖向渐变 + 顶部高光 + 1px 描边，跟着用户的外观设置走 |
| 拖动 | 悬浮态自由拖；锚定态松手吸附到图标网格并挤走挡路的图标 |
| 缩放 | 悬浮态右下角手柄；锚定态右键「编辑」出八点控制点，按格步进 |
| 右键菜单 | 编辑 / 切换形态 / 组件尺寸 / 组件设置… / 关闭，全自动 |
| 关闭按钮 | 悬浮态右上角 ×，与右键「关闭」同一条路（从桌面移除，可在组件库恢复） |
| 设置持久化 | `entry["settings"]` 落 state.json，重开还在 |
| 显隐 / 翻页 | 托盘勾选、切页自动隐藏，都不用你管 |

### 3.2 可以用的成员

| 成员 | 含义 |
| --- | --- |
| `self.rect()` | 当前尺寸（逻辑像素）。**唯一**该用来算布局的东西 |
| `self.entry` | 这个实例的持久化字典（`settings`、`col/row`、`x/y` …）。要存自己的数据就放这里并 `self.storage.save()` |
| `self.storage` | 全局配置读写：`get_setting(k)` / `set_setting(k, v)` / `save()` |
| `self.style` | 用户外观（见 §4） |
| `self.anchored` | 当前是锚定还是悬浮 |
| `self.interactive` | 来自 manifest 的 `interactive` |

### 3.3 生命周期钩子（可选覆盖）

| 钩子 | 时机 |
| --- | --- |
| `paint_content(p)` | 每帧。**必须**用 `self.rect()` 算坐标，任何尺寸都要好看 |
| `on_settings_changed()` | 用户点「应用」后。第一行写 `super().on_settings_changed()` |
| `paintEvent(e)` | 一般**不要**覆盖。要画东西请用 `paint_content` |

### 3.4 定时刷新

组件基类不会替你起定时器。需要动态内容（时钟、监控）就自己起：

```python
from PySide6.QtCore import QTimer

def __init__(self, storage, entry, interactive=False):
    super().__init__(storage, entry, interactive)
    self._timer = QTimer(self)
    self._timer.timeout.connect(self.update)
    self._timer.start(1000)      # 每秒重绘一次
```

**别在 `paint_content` 里做重活**：它每帧都可能被调用，一次网络请求就会
让整个桌面掉帧。要取数据请在定时器里取，存到 `self._model`，画的时候只读。

## 4. 配色：读 `self.style`，别写死颜色

`self.style` 是一个不可变调色板，值来自用户的外观设置（未设置则跟随主题）：

| 字段 | 用途 |
| --- | --- |
| `style.text` | 主文字 |
| `style.dim` | 次要文字（标签、单位） |
| `style.faint` | 更弱（网格线、占位、空态） |
| `style.accent` | 强调色（进度条、选中态、图表主色） |
| `style.bg` | 用户自定义背景色，`None` = 跟随主题玻璃 |
| `style.alpha` | 整体不透明度（0.2 ~ 1.0） |
| `style.radius` | 圆角 |

`style.dim` / `style.faint` 是从 `style.text` 派生出来的（降透明度，不掺灰），
所以**不要**自己写 `QColor(text.red(), text.green(), text.blue(), 128)`——
用户改了文字颜色，你那份手算的就对不上了。

字体统一用 `theme.ui_font(字号, bold=True/False)`，别自己 `QFont("Microsoft YaHei")`：
打包后的机器不一定有你写的那款字体。

## 5. 设置项：`settings` 数组

每一项是一个字段声明，主程序自动生成控件、自动存盘、自动回填：

```json
{"key": "city", "label": "城市", "kind": "text", "default": "北京",
 "placeholder": "如：上海", "hint": "留空则按 IP 定位", "group": "数据源"}
```

| `kind` | 生成的控件 | `default` 类型 |
| --- | --- | --- |
| `text` | 单行输入框 | 字符串 |
| `int` | 数字框（配合 `min` / `max`） | 整数 |
| `bool` | 开关 | `true` / `false` |
| `combo` | 下拉框（需给 `choices`） | 选项里的值 |
| `color` | 取色器 + 「清除」（空 = 跟随主题） | `"#RRGGBB"` 或 `""` |
| `float` | 滑条（配合 `min` / `max`） | 浮点数 |

`combo` 的 `choices` 是 `[值, 显示文字]` 的数组：

```json
{"key": "unit", "label": "单位", "kind": "combo", "default": "c",
 "choices": [["c", "摄氏度"], ["f", "华氏度"]]}
```

`group` 相同的字段会被分到同一段（不写就是「组件设置」）。**外观类字段不要
自己声明**——主程序已经统一加了一份，你重复声明会被忽略。

读取方式：

```python
def _cfg(self):
    s = self.entry.get("settings") or {}
    return {"city": s.get("city") or "北京",
            "unit": s.get("unit") or "c"}
```

## 6. 本地预览调试

```bash
python tools/widget_dev.py examples/widgets/hello
python tools/widget_dev.py 我自己的组件/hello        # 直接指向你的目录
python tools/widget_dev.py build/widgets/hello-1.0.0.zip
```

调试器做三件事：

1. **校验**：manifest 与模块的错误（含 traceback）直接打在窗口里，不用你猜；
2. **真机预览**：按 manifest 的每种跨度实例化**真实组件**——玻璃底、字号、
   留白、拖动、右键菜单、组件设置，全都和桌面上一样。组件库缩略图看不出这些；
3. **热重载**：改完 `widget.py` 点「重新加载」，不用关掉调试器。

两个已知行为：

- 调试器是普通窗口，预览组件会被临时改成"不挂桌面带"，否则它会被调试
  窗口压在下面，看起来像没显示。
- 调试用的 Storage 写在系统临时目录，**不会**动你真实的 state.json。

## 7. 打包与导入

```bash
python tools/pack_widget.py examples/widgets/hello
# -> dist/widgets/hello-1.0.0.zip
```

脚本会**先校验再打包**（走的就是组件库导入时那条路径），所以"能打出来"
基本等于"能装上"。参数：

| 参数 | 说明 |
| --- | --- |
| `-o, --out <路径>` | 指定输出位置 |
| `--no-validate` | 跳过校验（只在没装 PySide6 的机器上救急） |

导入：主程序 ▸ 设置 ▸ 组件库 ▸ 页脚「导入组件…」→ 选 zip。
`manifest.json` 必须在 zip 根目录（脚本默认就是这么打的）；手工打包时要
小心多套一层目录或多出 `__MACOSX` 之类，会让导入器找不到 manifest。

导入后：

- 组件立刻出现在组件库，**不用重启**；
- 组件目录落在 `%APPDATA%\DesktopOrganizerDemo\widgets\<id>\`；
- 卡片上有「卸载」按钮（只有插件有），卸载 = 删目录 + 移出注册表，
  已经放到桌面上的实例会一并消失。

## 8. 常见错误速查

| 导入时的报错 | 原因 | 修法 |
| --- | --- | --- |
| `缺少 manifest.json` | zip 里没这个文件，或它在子目录里 | 用 `tools/pack_widget.py` 重打 |
| `id 只能是小写字母开头…` | id 有大写、连字符、以数字开头，或长度不对 | 改成 `my_widget` 这种 |
| `id 'clock' 与内置组件同名` | 想覆盖内置组件 | 内置组件不可覆盖，换个 id |
| `缺少 factory（组件类名）` | 没写 `factory` | 写上类名，和 `widget.py` 里一致 |
| `模块里找不到 factory='Xxx'` | 类名拼错，或类写在 `if` 里 | 检查拼写、放模块顶层 |
| `factory 必须是 widget_glass.GlassWidget 的子类` | 继承了 `QWidget` 或别的基类 | 改成 `from deskorg.widget_glass import GlassWidget` |
| `模块导入失败：ModuleNotFoundError: No module named 'deskorg'` | 用了 `from src.xxx import` 或裸 `import widget_glass` | 统一用 `from deskorg.xxx import` |
| `压缩包含不支持的文件类型：xxx.pyd` | 打了编译产物 | 只打源码与素材 |
| `压缩包含非法路径（zip-slip）` | 包里有 `../` 或绝对路径 | 重新在干净目录里打包 |
| 组件加进桌面但一片空白 | `paint_content` 没写，或坐标算到 `rect()` 外面 | 用 `self.rect()` 算，先画个大色块自测 |
| 组件显示成方块字 | 用了 `QT_QPA_PLATFORM=offscreen` 截图 | 那是无字体平台，不是你的 bug |
| 改了设置颜色没变 | `on_settings_changed` 没调 `super()` | 补上第一行 |

启动时加载失败的插件**不会**拦住程序：错误写进
`%APPDATA%\DesktopOrganizerDemo\plugin_error.log`，主程序照常起来。排查
"我装了但组件库里没有"先看这个日志。

## 9. 能做与不能做

**能做**

- 读配置、写自己的数据到 `entry`、发 HTTP 请求（用 `deskorg.weather_api`
  里的做法做超时与降级）。
- 用任何 PySide6 能力画东西：文字、图形、图片、图表。
- 引用同目录下的图片素材（`Path(__file__).parent / "logo.png"`）。

**不能做 / 不建议**

- **覆盖内置组件**：注册表直接拒绝。
- **依赖主程序的内部模块**：`desktop_window`、`win32_layer`、`iconwidget`
  这些不在 SDK 白名单里，升级会变。SDK 只有：
  `theme`、`widget_glass`、`widget_style`、`widget_base`、`effects`、
  `grid_flow`、`storage`、`weather_api`、`widget_registry`。
- **在 `paint_content` 里做 IO / 网络 / 睡眠**：每帧调用，会拖垮整个桌面。
- **开新窗口、改别人的窗口**：组件是桌面的一部分，弹窗会盖住用户的应用。

**安全声明**：插件就是 Python 代码，能力与主程序相同——**没有沙箱**。
程序只做了"不覆盖内置组件、限制包内文件类型与体积、加载失败不拖垮启动"
这三层护栏，不做权限隔离。请只安装你信任来源的组件。

## 10. 参考实现

| 位置 | 看什么 |
| --- | --- |
| `examples/widgets/hello/` | 最小可用组件：manifest + 一个类 + 预览函数 |
| `src/widgets_clock.py` | 时间类：定时器 + 纯函数 `draw()` + 固定时刻预览 |
| `src/widget_glass.py` | `GlassWidget` / `paint_glass()` / 兜底预览 |
| `src/widget_registry.py` | `WidgetSpec` / `FieldSpec` 的权威定义（字段含义以代码为准） |

内置组件与外部组件的唯一差别是"内置组件被写死在注册表里、不能卸载"。
把 `src/widgets_clock.py` 改成一个插件目录，效果完全一样。
