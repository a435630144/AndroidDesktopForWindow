一款把 Windows 桌面变成**手机桌面**的第三方桌面美化整理软件：安卓式图标网格、真弹簧物理的滑动让位、液态玻璃文件夹，以及一组可锚定进网格的桌面小组件。

## 本版新增（6.1.0）

- **首次安装启动的新手操作指引**：装好第一次打开，自动进入 7 步引导——欢迎 → 图标（双击 / 拖动 / 多选）→ 拖成文件夹 → 分页 → Dock 栏 → 小组件 → 收尾。遮罩压暗全屏、只在高亮元素处开一个圆角洞，讲的就是你眼前这套真实界面，不是示意图
- **操作方式**：单击遮罩 / `→` / 空格 = 下一步，`←` = 上一步，`Esc` = 跳过；最后一步「开始使用」收尾。跳过也算看过，不会每次启动重复打扰
- **按实际内容生成**：分页 / Dock / 小组件三步只在对应元素真的存在时出现（没开 Dock 就不讲 Dock，桌面只有一页就不讲翻页）；桌面一个图标都没有时，高亮区退回网格左上角，指引照样走完
- **随时重看**：设置 ▸ 通用 →「查看新手指引」。以后版本加了新玩法，只要把指引版本号 +1，老用户会重新看到（已看过的步骤不会重复计数）
- 同页新增桌面快捷键说明：`Ctrl+C` / `Ctrl+V` 复制粘贴文件
- 顺带：下线旧的首次运行托盘气泡——那段文案还在说「系统桌面保持原生」，与现在默认的桌面整理模式相反

## 实现要点

- 遮罩是独立置顶分层窗（`Qt.Tool` + 透明背景），不挂桌面带：Dock 和小组件是分层窗，挂在桌面带里盖不住它们；同时它天然吞掉鼠标，指引期间不会边看边把布局拖乱
- 聚光灯用 `QPainterPath` 的奇偶填充规则挖洞（不是四块遮罩拼出来的），洞边一圈强调色描边 + 三层外发光；高亮块位移用项目统一的弹簧曲线，系统关闭动画时直接落位
- 卡片是子控件（真 `QLabel` + 真按钮），文字换行、省略、屏幕阅读器都交给 Qt；自绘文本在 125% / 150% 缩放下必然截断——这个项目已经踩过
- 高亮目标全部从**真实窗口几何**取（图标控件、Dock 条带、组件窗口、页点），并裁剪到屏幕内；目标被拖到屏幕外时不会把卡片顶到角落

## 既有能力（6.0.x）

Dock 尺寸四项独立可调、音乐组件读真实播放信息并可拖动 seek、开发者选项独立分页、桌面 Ctrl+C / Ctrl+V、GitHub 更新检测与关于作者、组件商店、英文界面、安装器双语言。
