一款把 Windows 桌面变成**手机桌面**的第三方桌面美化整理软件：安卓式图标网格、真弹簧物理的滑动让位、液态玻璃文件夹，以及一组可锚定进网格的桌面小组件。

## 本版修复（5.0.1）

- **修复界面语言不生效（中英混搭）**：v10a（5.0.0）的便携版与安装包漏打包了语言词表，启动后查词表为空，界面上大量文案直接显示 `settings.title`、`button.done` 这类内部 key，看起来像中英文混搭。本版把词表打进包内，并补上冻结态取词与打包契约两条回归判据，自检报告会输出词表规模与抽样译文，同类问题以后启动自检就能发现
- **组件库响应式布局（不再横向滚动）**：卡片区改为「放得下 2 列才 2 列」——窗口窄时自动 1 列并把卡片拉宽，窗口够宽才恢复双列，横向滚动条从根上取消；本地组件与组件商店两个页签同一套规则。设置窗最小宽度同步放开（860 → 600），窄窗形态可达
- 适用范围：设置面板、桌面面板小组件、托盘菜单、右键菜单、组件库等此前受同一问题影响的全部界面

## 既有能力（5.0.0）

组件商店（gitee 优先 / github 兜底 / sha256 校验，本地与商店双页签，首批世界时钟与倒计时）、英文界面（自动 / 中文 / English 即时切换）、安装器双语言 + 美化、改名 PhoneDesktop（数据目录一次性自动迁移）、9 条实机反馈闭环、Dock 默认圆角 12px（0~26 可调）。详见 [5.0.0 发布说明](5.0.0.md)。

## 质量与安装

89 个测试文件 / 2313 条断言 + 冒烟全绿（含冻结态取词 I16、打包契约 I17）；安装包免管理员。附件两件：`_Portable.zip`（便携版，解压即用）与 `_Setup.exe`（安装版，带桌面快捷方式与卸载入口）。
