# 7.0.2（v12c）· 安装器按系统环境自动选择语言

安装包不再弹「选择安装语言」对话框，改为**按 Windows 界面语言自动匹配**：

- 简体中文系统 → 中文安装向导
- 其它语言系统 → English 安装向导
- 仍可命令行覆盖：`Setup.exe /LANG=english`

安装完成时把选出的语言写入应用数据目录（`install_lang`），程序界面语言与安装向导保持一致；设置里的「语言」若显式选过中文/English，仍以用户选择为准。

**技术要点**：中文语言包补上 `[LangOptions] LanguageID=$0804`，Inno 才能真正匹配到简体中文（此前会按列表第一项兜底）。
