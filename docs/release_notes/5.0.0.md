一款把 Windows 桌面变成**手机桌面**的第三方桌面美化整理软件：安卓式图标网格、真弹簧物理的滑动让位、液态玻璃文件夹，以及一组可锚定进网格的桌面小组件。

## 本版新增（V10 第一批 · 5.0.0）

- **组件商店**： app 不再内置全部组件——按需从商店下载。商店优先走 gitee，不通或慢时自动切 github 兜底；每个安装包带 sha256 校验，坏包装不上、也拖不垮启动。商店**永不覆盖内置组件**（同名显示「内置」），断网也有随包分发的 8 个种子组件可用。首批上架：**世界时钟**、**倒计时**
- **设置 ▸ 组件库双页签**：「本地组件」管已装的，「组件商店」逛新的；商店页签第一次打开才发网络请求
- **界面语言**：设置 ▸ 通用顶部新增「界面语言」（自动 / 中文 / English），**立即生效**整窗重建；已覆盖设置六页、托盘全部菜单与气泡、桌面右键菜单、组件库、组件设置弹窗与版本串
- **安装器双语言 + 美化**：安装向导中文界面（自维护覆盖层）+ 英文对照，120% 向导、安装包图标与产品图焕新；免管理员安装，卸载可选清理用户数据
- **改名 PhoneDesktop**：exe 名 / 安装目录 / `%APPDATA%` 数据目录一起改，**旧数据一次性自动迁移**（复制成功才删旧）

## 本版修复（9 条实机反馈 + Dock 圆角）

- 小组件周围的操作交互盲区；Dock 栏拖入应用与独立设置分页（图标大小 / 圆角 / 不透明度 / 悬停放大 / 指示点）；设置里切换 Dock 位置不生效
- 网格模式下新添加小组件默认为网格模式；组件右键名称按「网格 / 无界」双模式区分；删掉设置里没用的「恢复组件」按钮
- 小组件新增**填充百分比**（默认不填满）——并排摆放不再贴边；尺寸调节的辅助虚线压到组件边缘、定位小球同步外偏
- 桌面面板组件重构（编辑配色生效、天气与天气组件冲突解除）；**Dock 默认圆角收小**：51px 厚条带不再默认胶囊，改为**圆角 12px**（0~26 可调，超过半厚自动夹紧）

## 既有能力

图标网格与滑动让位、拖拽合并文件夹、橡皮筋多选、时钟 / 便签 / 桌面面板（搜索 · 快捷文件夹 · 磁盘 · 最近下载 · 天气）/ 系统监控 / 待办清单 / 日历 / 天气八类内置小组件（支持**锚定非悬浮**模式，可拖拽缩放、与图标互相让位）、自动重挂守护、崩溃日志、单实例。

## 质量与安装

89 个测试文件 / 2308 条断言 + 冒烟全绿；安装包免管理员。附件两件：`_Portable.zip`（便携版，解压即用）与 `_Setup.exe`（安装版，带桌面快捷方式与卸载入口）。
