# 7.0.0（v12a）· 设置面板修复 · Dock 四向内边距与位置 · 监控组件 2x1

## 修复

- **设置面板深色背景下黑字**：通用 `QLabel` 规则缺 `color` 声明，无名标签显示系统默认黑字；`QCheckBox`（非 Switch）同理。统一补亮色规则 + `QToolTip` 样式。
- **组件设置对话框**同样补 `QCheckBox` / `QSpinBox` / `QLineEdit` / `QToolTip` 色值。

## Dock 栏

- **四向内边距**：上/下/左/右独立调节（2~20 px），替代旧的单一内边距值。未设置时回退旧值。
- **屏幕位置调节**：新增「屏幕位置」卡片，支持水平/垂直偏移（-200~200 px）与沿边居中开关。
- **重置按钮**：尺寸与间距 / 屏幕位置 / 外观三张卡片各有「重置」按钮，一键恢复出厂值。

## 小组件

- **系统监控改 2x1**：紧凑横排「标签 / 进度条 / 百分比」三行布局，替代旧 2x2 圆环。右键可切 4x2 宽版。
- 同一组件的不同尺寸现在各有独立 UI（参照天气组件的响应式做法）。
