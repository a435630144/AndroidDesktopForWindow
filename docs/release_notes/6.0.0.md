一款把 Windows 桌面变成**手机桌面**的第三方桌面美化整理软件：安卓式图标网格、真弹簧物理的滑动让位、液态玻璃文件夹，以及一组可锚定进网格的桌面小组件。

## 本版新增（6.0.0）

- **Dock 栏更多自定义**：图标大小（24~56px）、图标间隔（0~24px）、条带内边距（2~20px）、悬停放大倍数（100%~150%）四项独立可调。四项各管一件事——想要"更紧凑但图标别变小"也能做到。改这三项走轻量路径（只重排条带，不重建图标），拖步进器不再卡顿；改图标大小仍走全量重排（必须重建图标）
- **音乐组件读当前音频**：接上 Windows SMTC，读到真实曲名 / 艺人 / 播放状态 / 进度 / 时长，**进度条可拖动 seek**（松手才落 seek，拖动中不打断播放器）。优先级三级：SMTC → 播放器窗口标题（`歌名 - 歌手`，注明「仅曲名 · 播放器未提供进度」）→ 演示态。侧车用 PowerShell 托管代码读 WinRT（ctypes 手工投影 vtable 会 AV 崩进程，见 `src/media_session.py` 模块头）
- **开发者选项独立分页**：顶部一个总开关，关闭时下面整组置灰不可交互；「网格线 / 原点 / 几何信息」「组件碰撞体积」「帧率与绘制面积」「组件窗口一致性」各自一个开关；网格原点定位从「高级」搬到这里。分项默认全开，总闸打开即旧行为
- **桌面 Ctrl+C / Ctrl+V**：桌面窗口是 `WS_EX_NOACTIVATE`（永不获焦点），键盘事件到不了 `keyPressEvent`，改用低层键盘钩子。只在前台是桌面、指针底下没有应用窗口、且确实有选中项 / 剪贴板里有本地文件时接管——宁可漏一次，不可误吞一次
- **更新检测 + 关于作者**：「高级」页从 GitHub 最新 Release 比对版本号（后台线程，网络慢不冻界面），发现新版本可直接跳下载页；新增作者介绍与抖音 / 哔哩哔哩入口
- **侧栏 GitHub 图标**：设置面板左下角一键进仓库
- 顺带修掉：Dock 位置下拉显示英文（`POSITION_LABELS` 解包顺序写反，切位置写进 storage 的是中文）、「高级」页副标题过期

## 既有能力（5.0.x）

组件商店（gitee 优先 / github 兜底 / sha256 校验）、英文界面（自动 / 中文 / English 即时切换）、安装器双语言、Dock 栏（位置 / 圆角 / 不透明度 / 边框）、组件碰撞可视化、桌面复制粘贴之外的整套整理能力（文件夹、分页、框选、自动排列、每页排序规则）。

## 质量与安装

95 个测试文件 + 冒烟全绿；`scripts/check_docs.py` ERROR 0。新增回归：`test_dock_custom.py`（四项旋钮）、`test_widget_music.py` M13~M17（侧车协议 / 组合源优先级 / 标题解析 / 拖动 seek / 仅曲名档）、`test_dev_options.py`（总闸与分项独立性，含像素级）、`test_desktop_hotkeys.py`（接管判据 / 长按节流 / 复制内容）、`test_updater.py`（版本号比较 / 错误文案 / 后台信号）。

安装包免管理员。附件两件：`_Portable.zip`（便携版，解压即用）与 `_Setup.exe`（安装版，带桌面快捷方式与卸载入口）。

> 注：PyInstaller 产物可能被杀软误报，需加白名单。音乐组件的 SMTC 读取依赖系统 PowerShell；被企业策略禁用时自动降级到窗口标题档。
