一款把 Windows 桌面变成**手机桌面**的第三方桌面美化整理软件：安卓式图标网格、真弹簧物理的滑动让位、液态玻璃文件夹，以及一组可锚定进网格的桌面小组件。

## 本版新增（V9 第一批）

- **全组件外观自定义**：每个组件都能配背景色 / 不透明度 / 文字色 / 强调色 / 圆角；组件库预览与桌面渲染同一个 `draw()`，改了立即生效
- **组件插件平台**：写一个目录或 zip 就能装进桌面（附《组件开发指南》）；zip 解包带白名单后缀、zip-slip 与体积三重护栏，坏插件只记日志不拖垮启动
- **组件库并入设置面板**：顺手修掉「从设置面板打开组件库后被压在下面点不动」——根因是组件库窗口被设置窗拥有又继承应用级模态，取消独立窗口后从结构上一起消失
- **每页独立排序规则**：修掉「自动排布 / 拖到下一页松手跳回初始页」；目标页从 `page*rpp` 起排、原页补洞、其它页一格不动
- **手机式双交互**：单击启动 / 长按菜单 / 多选批量 / 滑动翻页，可与 Windows 原生交互切换

## 既有能力

图标网格与滑动让位、拖拽合并文件夹、橡皮筋多选、时钟 / 便签 / 桌面面板（搜索 · 快捷文件夹 · 磁盘 · 最近下载 · 天气）/ 系统监控 / 待办清单 / 日历 / 天气八类小组件（支持**锚定非悬浮**模式，可拖拽缩放、与图标互相让位）、自动重挂守护、崩溃日志、单实例。

## 质量与安装

79 个测试文件 / 约 1900 条断言全绿；安装包免管理员，卸载会清理 `%APPDATA%` 数据。
附件两件：`_Portable.zip`（便携版，解压即用）与 `_Setup.exe`（安装版，带桌面快捷方式与卸载入口）。
