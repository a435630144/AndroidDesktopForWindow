## 🧊 液态玻璃（反馈 9）

设置 ▸ 外观新增「液态玻璃」卡片：一个总开关 + 三个表面开关（**文件夹弹窗 / Dock 栏 /
小组件背景**），四层光学各自可调强度：

- **透镜边缘**：贴边的渐隐反光带，模拟玻璃厚度的 fresnel（光从左上来：顶边最亮）
- **色散**：贴边框内侧四条细线，把白光拆成彩色镶边（顶冷蓝 / 左青 / 右紫 / 底暖粉）
- **材质颗粒**：细微噪点，去掉"塑料感"（feTurbulence 的静态近似）
- **流动扫光**：一道柔和高光 6.5 秒横扫一遍；**系统关闭动画时自动停**（与全局动效同一把闸）

叠加层画在既有玻璃之上、内容之下——不改变任何几何，改设置只重绘不重建。

## 🧩 组件按尺寸差异化布局（反馈 7）

同一个组件不再"一套内容缩放到底"，而是**按预设尺寸换布局**。首个落地是天气：

- **2×2（square）**：城市 / 大温度 / 描述 / 明日高低温，单栏纵排
- **4×2（wide）**：不是 2×2 的放大——左块**多出湿度 / 风力两个指标**，右栏三天预报
  每列带**温程条**（按三天全局温程归一切分，条子在轨道上的绝对位置 = 哪天更暖）
