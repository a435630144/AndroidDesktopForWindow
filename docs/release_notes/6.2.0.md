一款把 Windows 桌面变成**手机桌面**的第三方桌面美化整理软件：安卓式图标网格、真弹簧物理的滑动让位、液态玻璃文件夹，以及一组可锚定进网格的桌面小组件。

## 本版改进（6.2.0）

- **音乐组件显示专辑封面**：从 Windows SMTC 的 `MediaProperties.Thumbnail` 读播放器发布的封面，落到 `%APPDATA%/PhoneDesktop/media_cover_<hash>.img`，组件按内容哈希缓存并圆角裁切绘制。换歌才重新读盘；缓存只保留最近 6 张，不会越积越多
- **拿不到时长就不画进度条**：窗口标题档、或播放器不发布 timeline 时，整条进度条（含已停用的空底轨）都不再渲染，按键行随之上移。以前那条暗底轨给人的观感是"进度卡在 0"，比没有更糟
- **顺带把 SMTC 读取链路修完整**：PowerShell 5.1 无法读取 WinRT 图片流（`OpenReadAsync()` 返回裸 `__ComObject`，`.Size` 静默为 0、转 `IInputStream` 直接抛异常），改用 `RandomAccessStream.CopyAsync` 反射拷贝进 `InMemoryRandomAccessStream` 再 `DataReader` 读字节。用内存流做了对照实验，**读出的字节与源文件完全一致**（见 `src/media_cover.ps1` 的实测记录）

## 关于「为什么网易云没有进度」

Windows 的 SMTC 是**播放器自愿实现**的接口：元数据、时间轴（进度/时长）、封面都是可选项。

- 网易云音乐 **Win32 原版不实现 SMTC**（社区文档：Lyricify「网易云音乐 Win32 原版并不支持 SMTC」；装 BetterNCM + InfLink 插件才会以插件身份上报）。所以本机只能走"窗口标题"兜底——拿得到歌名，拿不到进度和封面
- Spotify、QQ 音乐新版、Chrome / Edge 的网页播放器、Windows「媒体播放器」、VLC 等实现了 SMTC：曲名、艺人、进度、封面都能读到，进度条与拖动 seek 随之可用
- 本机实测：网易云在放歌时 SMTC 会话数为 **0**；系统「媒体播放器」播放同一个文件时能读到 `title/dur/pos`——说明读取链路正常，差异在播放器侧

## 质量与安装

96 个测试文件 + 冒烟全绿（`test_widget_music.py` 扩 M18~M22：封面协议字段 / 真图像素 / 缺文件降级 / 无时长不画条 / 空条无命中区 / 缓存清理只动自己的文件）；`scripts/check_docs.py` ERROR 0。

安装包免管理员。附件两件：`_Portable.zip`（便携版，解压即用）与 `_Setup.exe`（安装版，带桌面快捷方式与卸载入口）。
